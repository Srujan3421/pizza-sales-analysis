# pizza-sales-analysis
  
## Overview  
This project analyzes a pizza sales dataset to uncover sales patterns, pricing trends, and customer preferences. The analysis includes various visualizations and statistical insights.  
  
## Dataset  
- File: pizza_sales.csv  
- Contains information about pizza sales including:  
  - Pizza categories  
  - Prices  
  - Quantities  
  - Sizes  
  - Order dates/times  
  
## Analysis Components  
1. Data Loading and Cleaning  
2. Exploratory Data Analysis  
3. Statistical Analysis  
4. Visualizations:  
   - Sales Distribution  
   - Category Analysis  
   - Price Analysis  
   - Time Series Analysis  
   - Correlation Analysis  
  
## Libraries Used  
- pandas  
- matplotlib  
- seaborn  
- numpy  
  
## Key Findings  
1. Sales Patterns  
2. Price Distribution  
3. Category Performance  
4. Size Preferences  
5. Order Trends  
  
## Files Included  
- pizza_sales.csv (dataset)  
- pizza_analysis.py (main analysis code)  
- visualizations/ (folder containing all plots)
